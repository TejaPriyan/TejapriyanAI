# Security Policy

## Supported Versions

Security updates are applied to the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

Security and privacy are taken very seriously in **Teja Priyan AI**.

If you discover a security vulnerability or sensitive disclosure risk, please do **NOT** open a public GitHub issue.

Instead, please report it privately:
* **Email:** [teja1616150@gmail.com](mailto:teja1616150@gmail.com)
* **GitHub Security Advisory:** Submit a private advisory via the GitHub repository.

Please provide:
1. A description of the vulnerability.
2. Steps or proof-of-concept to reproduce the issue.
3. Potential impact.

You will receive an acknowledgment within 48 hours, and critical fixes will be prioritized immediately.
